🐾 Pet Adoption Center
📌 Overview

Pet Adoption Center is a Java-based application designed to simplify the pet adoption process. The system helps animal shelters manage pet records and enables users to view available pets and submit adoption requests. The project demonstrates Object-Oriented Programming (OOP) concepts along with efficient data management techniques.

✨ Features
Add and manage pet records
View available pets for adoption
Submit adoption requests
Search pets by ID or name
Update pet adoption status
Store pet information efficiently
User-friendly console-based interface
🛠️ Technologies Used
Java
Object-Oriented Programming (OOP)
Data Structures
Binary Search Tree (BST)
Arrays
Exception Handling
🎯 OOP Concepts Implemented
Encapsulation
Pet details are stored using private data members with public getter and setter methods.
Abstraction
Abstract classes or interfaces define common adoption operations.
Inheritance
Different pet types inherit common properties from a base Pet class.
Polymorphism
Different pet categories can implement adoption-related methods in their own way.
